# Global OpenCode Instructions

## Looking at code

- Prefer local checkouts over API calls when inspecting code. Do not overwrite unstaged changes when updating a checkout.

## Communication

- Use ASD-STE100.
- Explain your thought process before running any commands.
- Treat questions as requests for information only. Do not make changes, run side-effecting commands, or carry out the action being discussed unless the user explicitly asks you to do it with a clear imperative request.

## Data manipulation

- Favour bash/unix tools over programming languages for ad-hoc data manipulation and queries from structured data. If you must write code, use Python or TypeScript. Do not use Perl or Ruby.
